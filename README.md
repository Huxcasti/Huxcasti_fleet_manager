# Huxcasti_fleet_manager

## Modelo 3D Ford Transit 2020
La inspección 3D de WILX Logistics está preparada para utilizar el modelo auténtico Ford Transit 2020, suministrado por el usuario.

**Ruta esperada del archivo:** `assets/ford-transit-prime.glb`

El archivo es binario (~11.6 MB). Para activarlo en GitHub Pages hay que subir ese GLB al directorio `assets` del repositorio. El visor `realvan.js` lo carga desde el mismo dominio, y mantiene `van3d.js` como modelo de respaldo si no está disponible.

### Nota
Las fichas todavía incluyen vehículos Ford Transit, Ram ProMaster y Mercedes Sprinter; hasta que haya modelos propios para cada una, el visor usa la Ford Transit como referencia visual. Los datos del sistema siguen guardándose en el navegador.

## Rivian EDV · vista 3D
La sección **Flota** incluye una vista interactiva de la Rivian Amazon Electric Delivery Van mediante el reproductor oficial de Sketchfab (compatible con móvil y escritorio).

- Modelo: [Low Poly Car – Rivians Amazon Electric Van](https://sketchfab.com/3d-models/low-poly-car-rivians-amazon-electric-van-597d70bfcf7c43bba31ffffc51290624)
- Autor: [ROH3D](https://sketchfab.com/roh3d)
- Integración: iframe oficial; el archivo 3D y sus texturas se sirven desde Sketchfab.
- **Importante:** el modelo embebido es azul y **no contiene calcomanías de Prime**. La interfaz usa una presentación inspirada en los colores de la flota de Amazon, pero no modifica el modelo de terceros. Para personalizar la carrocería y agregar sus logos en la superficie del vehículo, se necesita un archivo 3D editable y una licencia que permita la modificación.
- La vista es ilustrativa y no añade una unidad ficticia al inventario ni altera el inspector de daños Ford Transit.
